Master's Thesis

ECG-TransCovNet: A Hybrid CNN-Transformer Architecture for Multi-Class Arrhythmia Detection in ECG Signals

Supervisor: Dr. Khalid Mehmood
University: Gomal University, Dera Ismail Khan
Year: 2024 – 2026

Developed a lightweight hybrid CNN-Transformer model for multi-class arrhythmia detection, optimized for resource-constrained healthcare settings like rural Pakistan.

✅ Achieved 99% accuracy with only 0.35M parameters, 1.40 MB model size, and 5.84 ms inference time on CPU.

Technologies:
Python TensorFlow Keras PyTorch Scikit-learn NumPy SciPy Matplotlib Google Colab
📊 Dataset: MIT-BIH Arrhythmia Database (50,000 synthetic heartbeats, 5 AAMI classes: N, S, V, F, Q)
